# Real-Life Scheduling Simulator

A micro project that models real-world scenarios—such as hospital patients, bank customers, printer jobs, or web requests—as classic CPU scheduling problems.

## 📌 Project Overview
This simulator bridges the gap between theoretical operating system concepts and practical daily scenarios. By treating real-world arrivals (like emergency patients or bank tokens) as processes, this tool helps visualize how different scheduling policies affect waiting times and resource management.

## ⚙️ Core Features
- **Real-World Mappings:**
  - **Hospital Triage:** Modeled via Priority Scheduling (critical emergencies handled first).
  - **Bank Counters:** Modeled via First-Come, First-Served (FCFS).
  - **Printer Queues / Web Requests:** Modeled via Shortest Job First (SJF) or Round Robin (RR).
- **Interactive Metrics:** Calculates and visualizes Turnaround Time (TAT) and Waiting Time (WT).
- **Web-Based Interface:** Built entirely using web technologies, running instantly inside any browser.

## 🧠 Scheduling Algorithms Modeled
- **First-Come, First-Served (FCFS):** Standard token-based customer service.
- **Shortest Job First (SJF):** Quick tasks handled first to reduce overall queue length.
- **Priority Scheduling:** Emergency/high-importance tasks given immediate attention.
- **Round Robin (RR):** Time-sharing execution for multi-user web environments.

## 🚀 How to Run the Project
1. Clone or download this repository to your computer.
2. Navigate to the main directory.
3. Open the `MICROPROJECT.html` file in any modern web browser (Chrome, Edge, Firefox, or Safari).
4. Enter your custom simulator inputs and click **Simulate / Run**.
